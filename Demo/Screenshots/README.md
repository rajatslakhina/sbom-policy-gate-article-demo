# Screenshots

None yet, on purpose.

This repo was built by an automated run. When it reached the Simulator step, Xcode on the build machine already had an unrelated project open, and the run's rule is to stop rather than click through someone's open work. So the `Demo` app target and `SBOMGateDemoView` have **not** been compiled or run.

What *has* been verified: `swift build` and `swift test` (33 tests, 0 failures) on Swift 6.0.3, and a static check of `Demo.xcodeproj/project.pbxproj`.

If you run it, a screenshot PR is welcome.
